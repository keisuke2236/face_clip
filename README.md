# 顔写真自動編集ツール かんたん使い方ガイド (Windows版)

このツールは、たくさんの写真から人の顔を見つけて、顔を中心に正方形 (80x80ピクセル) に切り抜いてくれるツールです。

## 0. 初回限定の準備
[Python公式サイト](https://www.python.org/downloads/) から最新版をダウンロードしてインストールします。
**【重要！】** インストール画面で **`Add Python X.X to PATH`** または **`□ Add python.exe to PATH`** のチェックボックスに **必ずチェックを入れてください**。

## 2. 詳細なツールの使い方
1.  **画像を準備:** 編集したい顔写真が入ったフォルダ (例: `input_images` フォルダ) を、手順1で作ったフォルダ (`顔編集ツール` フォルダ) の **中** に置きます。
2.  **コマンドプロンプトを開く:** Windowsの検索で `cmd` と入力し、「コマンド プロンプト」を開きます。
3.  **フォルダを移動:** コマンドプロンプトで、`cd` コマンドを使って `顔編集ツール` フォルダに移動します。
    * 例: デスクトップに `顔編集ツール` フォルダを作った場合
        ```bash
        cd Desktop\顔編集ツール
        ```
    * (フォルダ名にスペースを含む場合は `cd "フォルダ 名"` のようにダブルクォーテーションで囲みます)
4.  **ツールを実行:** コマンドプロンプトで、以下のコマンドを入力してEnterキーを押します。 `[画像フォルダ名]` の部分には、手順1で用意した画像フォルダの名前に置き換えてください。
    ```bash
    python edit_agent_image.py [画像フォルダ名]
    ```
    * 例: `input_images` という名前のフォルダを処理する場合
        ```bash
        python edit_agent_image.py input_images
        ```
5.  **結果を確認:**
    * 処理が終わると、`顔編集ツール` フォルダの中に `edited_images` というフォルダが自動で作成されます。
    * この `edited_images` フォルダの中に、編集された画像 (元のファイル名に `_edited` が付いたPNG形式の画像) が保存されています。

## 3. うまくいかないとき

* **「情報: 顔が検出されませんでした」と表示された:**
    * 写真の顔が小さい、横顔、暗いなどの理由で顔が見つけられなかった場合です。
    * この場合、顔ではなく写真の中央部分が切り抜かれます。別の写真で試してみてください。
* **エラーが出た場合:**
    * **`'python' は...` エラー:** Pythonインストールの際、「Add Python to PATH」のチェックを忘れた可能性が高いです。Pythonを入れ直してみてください。
    * **`ModuleNotFoundError...` エラー:** 準備の「ライブラリのインストール」がうまくできていません。`pip install opencv-python Pillow` をもう一度試してください。
    * **`FileNotFoundError...` エラー:**
        * `cd` コマンドで正しく `顔編集ツール` フォルダに移動できていますか？
        * `python edit_agent_image.py [画像フォルダ名]` の `[画像フォルダ名]` は合っていますか？ (`顔編集ツール` フォルダの中にある画像フォルダの名前です)
    * **`エラー: 顔検出ファイルが見つかりません...` エラー:** `edit_agent_image.py` と `haarcascade_frontalface_default.xml` が同じ `顔編集ツール` フォルダに入っているか確認してください。
